# Homeschool Management App

> Professional homeschool tracking and compliance software for Pre-K through 5th grade

**Note:** This is proprietary software. Source code is not publicly available.

## Overview

A comprehensive desktop and mobile application for homeschool families to:

- Track daily learning activities
- Manage curriculum packages
- Monitor student progress and milestones
- Generate compliance reports
- Discover educational resources
- Plan field trips and events

## Features

- **Activity Tracking**: Log worksheets, videos, reading, writing, hands-on activities, and more
- **Curriculum Management**: Track curriculum packages by student and subject
- **Milestone Tracking**: Celebrate achievements with star rewards
- **Compliance Reports**: Generate portfolio-ready documentation
- **Resources Library**: Quick access to educational websites and apps
- **Field Trip Planning**: Organize outings and events
- **Multi-Student Support**: Manage multiple children with different grade levels

## Tech Stack

- **Desktop**: Electron + React + TypeScript + DuckDB
- **Mobile**: React Native + Expo + SQLite
- **UI**: Tailwind CSS + Design System
