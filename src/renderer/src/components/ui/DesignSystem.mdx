# Homeschool Design System

A consistent, accessible design language for the Homeschool app across desktop and mobile platforms.

## Design Philosophy

The Homeschool app uses a **warm, approachable, and educational** design language that feels friendly to families while maintaining clarity and professionalism for tracking academic progress.

### Core Principles

1. **Clarity First** - Information should be immediately scannable
2. **Student-Centric Colors** - Each child has a distinctive color for easy identification
3. **Encouraging Tone** - Success states use warm, positive colors
4. **Accessible** - WCAG AA compliant contrast ratios
5. **Consistent** - Same patterns on desktop and mobile

## Components

### Button Variants

- **Primary**: Main actions (fuchsia background)
- **Secondary**: Alternative actions (gray background)
- **Outline**: Tertiary actions (border only)
- **Ghost**: Minimal actions (no background)
- **Danger**: Destructive actions (red)

### Button Sizes

- **sm**: 32px height, 12px padding
- **md**: 40px height, 16px padding
- **lg**: 48px height, 20px padding

### Card Patterns

Cards are the primary container for content groupings:

- White background
- 12px border radius
- 1px border in `#e5e7eb`
- Subtle shadow
- 16-24px padding

### Badge Patterns

Badges indicate status or categorization:

- Rounded (4px radius)
- Small padding (6-8px horizontal, 2-3px vertical)
- Medium font weight
- Pastel background with dark text

## Accessibility

- All interactive elements have visible focus states
- Color contrast meets WCAG AA (4.5:1 for text)
- Touch targets are minimum 44x44px on mobile
- Icons have aria-labels when used alone
- Form inputs have associated labels

## Animation

- Use `duration-200` for most transitions
- Use `duration-300` for larger state changes
- Prefer `ease-out` for entering, `ease-in` for leaving
- Respect `prefers-reduced-motion`
